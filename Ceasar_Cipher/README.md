## 🧭 About

The **Caesar Cipher** is one of the simplest and oldest substitution ciphers.

It encrypts a message by shifting each alphabetic character by a fixed number of positions.

For example, with a key of **3**:

```text
A → D
B → E
C → F
...
X → A
Y → B
Z → C
