## 📂 Projects

### 🔐 1. Caesar Cipher

A Python implementation of the classical **Caesar Cipher**.

The project allows text to be:

- Encrypted using a shift key
- Decrypted using the same key
- Processed in both uppercase and lowercase
- Preserved with spaces and special characters

**Concepts practiced:**

`Python` • `Cryptography` • `Encryption` • `Decryption` • `String Manipulation`

---

### 🔎 2. Python Port Scanner

A lightweight **TCP port scanner** written using Python sockets.

The scanner accepts a target and a port range, attempts TCP connections, and reports ports that are reachable.

It also uses **multithreading** to perform multiple port checks concurrently.

**Concepts practiced:**

`Python` • `Sockets` • `TCP` • `Ports` • `Multithreading` • `Network Reconnaissance`

---

### 🕵️ 3. Packet Sniffer

A basic Ethernet packet sniffer built with Python raw sockets.

The project captures Ethernet frames and extracts information from the Ethernet header, including:

- Source MAC address
- Destination MAC address
- Ethernet protocol

This project helped me understand how raw network data can be captured and interpreted at the Ethernet layer.

**Concepts practiced:**

`Python` • `Raw Sockets` • `Ethernet` • `MAC Addresses` • `Packet Analysis` • `Networking`

---

### 🌐 4. Network Traffic Analyzer

A more advanced networking project focused on **live traffic monitoring and analysis**.

The analyzer captures network traffic and presents useful information through a terminal dashboard.

It includes features such as:

- Live packet monitoring
- Source and destination information
- Protocol identification
- Traffic statistics
- Network host tracking
- Basic security-event detection
- CSV session export
- PCAP export

The project also gave me practical experience working with **Scapy, packet capture, Npcap, and Wireshark-based analysis**.

**Concepts practiced:**

`Python` • `Scapy` • `Network Monitoring` • `Packet Analysis` • `PCAP` • `Wireshark` • `Basic Threat Detection`
